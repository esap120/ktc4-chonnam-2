# 차선 표시 영상 + 사용자 전체 정답 힌트 실험

2026-10-10 · 6영상 × 3회, 실제 18호출 완료 · 운영 코드 변경 없음

**정답지를 모두 제공하자 18/18회가 위반 존재를 긍정했다. 그러나 정답 시각을 말하는 것과 영상에서 같은 차량의 실제 횡단을 설명하는 것은 달랐다.** C05 첫 사건과 C10은 각 3회에서 차량·이동 방향·대략적인 사건 구간이 화면 관찰과 부합했다. 다른 사건의 차량 연결이나 차로 진입 완료는 틀리거나 확인되지 않았다. 18/18을 검출 정확도 100%로 해석하지 않는다.

## 입력과 비교 조건

[직전 남은 실선 영상 실험](gemini-green-crossing-remaining-2026-10-10.md)의 같은 6영상, 각각 원본 전체 60초를 사용했다. 원본 2fps 관측 120개를 담은 `overlay-api-half-speed.mp4`를 **바이트 단위로 그대로 재사용**했다. 영상의 차선 모델은 PP-LiteSeg이며 초록=solid, 분홍=dashed, 노랑=double_yellow다. 실선·점선 혼합과 구조물 오탐도 수정하지 않았다.

- API 입력은 차선 표시본 하나, 1280×720, 음성 없음, 120초의 0.5배속 영상이다. 원본은 모델에 보내지 않고 사람의 사후 대조에만 사용했다.
- 요청·응답 모델 `gemini-3.8-flash`, reasoning `low`, 최대 출력 2,000토큰, 자동 재시도 0. 각 영상 3회 순차 호출이며 18회 모두 `OK`, `finish_reason=stop`이다.
- 응답은 자유 서술이며 화면 `t=`의 **원본 시각**을 사용한다. 응답 시각에 다시 0.5를 곱하지 않는다.
- 유일한 실험 변경은 기존 초록선 횡단 프롬프트 뒤에 **현재 파일명과 전체 정답지**를 추가한 것이다. 대상 사건만 추출하거나 정답지를 요약하지 않았다.
- 전체 정답지에는 다른 영상의 사건·정상 구간, 이전 실패 메모, 도색 정보와 수정 이력도 들어 있다. 최신 수정 내용을 사용하도록 안내했다. 따라서 단순한 ‘유형+시각’ 힌트 실험과 구별한다.
- 현재 6영상 중 C05 첫 사건에는 오른쪽 검은 차량이라는 기존 사용자 힌트가 있다. 나머지 사건의 차량 ID·바퀴 접점·정밀 교차 시각은 새로 만들어 주지 않았다. 다른 영상의 차량 설명도 전체 정답지에 포함되어 있다.
