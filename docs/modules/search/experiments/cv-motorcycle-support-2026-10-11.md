## 연결한 구조

M1은 로컬 AI Hub 안전모 YOLOv5 모델의 몸체 클래스2/3(`motorcycle`, `no_helmet_motorcycle`)만 사용한다. 머리 클래스0/1은 제외하고, 몸체끼리 IoU0.7 중복 제거 후 `MOTORCYCLE`로 정규화하며 bbox·점수를 보존한다. V1 자동차와는 별도 검출·추적 파일 및 `M1_` 후보 ID를 사용한다. 기본 V1 실행 방식은 유지된다.

M1만으로 보정을 재계산하면 움직이는 자동차가 마스크에서 빠지므로, 기존 V1의 motion·차선 좌표·scene epoch를 정확히 재사용한다. FrameSpec, 규칙, 원본 영상 목록·manifest 해시, 추적기의 원본 detection index를 검사한다. 기존 크기·가장자리·차선 지원·접지 점프·관측 공백·3회/0.4초 조건은 유지한다. bbox 하단 중앙은 실제 타이어 정답이 아닌 접지 대리점이며 출력은 `UNKNOWN`이다.

## 재현성과 검증 한계

동일 설정의 두 추론 결과는 비트 단위로 같지 않았다. 각각953검출·413개 높은 점수 검출이지만802프레임의 데이터가 다르다. confidence 최대 차이는0.001843이고 높은 점수 상자4개에서1px, 낮은 점수 상자1개에서21px 차이가 있었다. 원시 출력 차이를 무시하거나 원인을 CUDA 설정 하나로 단정하지 않았다. 최초의 완전 동일성 가정에 기반한 감사 실패 로그·소스도 보존하고 실제 차이를 기록했다. 두 캐시의 공식 CPU 추적·교차 재생 비교는 별도 `repeatability-*.json`에 기록한다.

두 캐시를 각각 공식 ByteTrack/BoT-SORT로 전체 재생한4회 대조를 마쳤다. 관측 수·ID·원본 검출 index·거리 표본 수·ID·기각 사유는 같았으며 두 실행 모두 후보0개다. 관측 점수·일부 원본 상자·추적기의 보정 상자·일부 거리 좌표는 달랐다. 최종 캐시의 CPU 재생은 실제 CLI의 추적·교차 출력과 지연 측정값을 제외하고 정확히 일치했다. 이번 후보 결과의 재현은 확인했지만 일반적인 추론 결정성을 보장하는 것은 아니다. 근거는 `repeatability-report.json`이다.
