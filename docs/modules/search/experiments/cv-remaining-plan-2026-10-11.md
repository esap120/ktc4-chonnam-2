## 원래 계획에서 남은 3묶음

1. **정답·검증 영상 확보:** 검수된 차량 bbox와 동일 차량 ID, 차선 곡선·유형·역할, 사건 대상 연결이 필요하다. 좌표 초안1,200프레임은 있으나 검수된 정답은 없다. 정상113개는 기존 평가 목록123개 중 위반 기록이 없는113개다. 선을 넘지 않은 영상에서도 잘못 경고하는지 확인하는 오탐 검증용이며, 목록·확인 기록은 있으나 실제 영상0/113이다. 기존 사건 시각과 사용자 육안 확인은 재입력하지 않는다.
2. **L2 실행 환경 해결:** 소스·가중치·설치된 MSVC를 확인했다. CUDA 컴파일러·필수 연산 모듈이 없고 Docker 엔진이 시작되지 않는다. 특정 오래된 Docker 연결 파일 접근 실패로 제한된 복구 시도도 실패했다. 기존 사용자 파일·컨테이너는 삭제하지 않았으며 L2 추론·속도 측정은 미실행이다.
3. **최종 선정·판정·검증:** 앞의 조건이 준비되면 실제 GT로 차량·추적기·차선 모델을 선정하고 원본 차선 ROI의 실선/점선·색상·중앙선 역할과 후보 점수를 구현·평가한다. 이후 정식 C0–C5 누적 비교·Top-K·정상 영상 분당 후보 발생량·독립 성능을 검증한다. L3에 없는 신뢰도를 임의 생성하지 않는다.

이 세 묶음이 끝나기 전에는 전체 완료로 표시하지 않는다. Fine 연결·운영 Search 통합·배포는 별도 후속 범위다.
