# CV_LANE_TRACK — 좌표 정리와 기존 사건 시간대 대조

작성일: 2026-10-10 · 상태: **좌표 변환·시간대 대조 완료 / 좌표 정확도·사건 정확도 미평가**

사용자의 “모두 확인했는데 모두 잘되어있어”를 차선 육안 검수 통과로 보존했다. 추가 시각 입력이나 반복 육안 검수 없이 기존 정답지와 좌표 자료를 정리했다.

## 완료한 작업

- 29개 작업의 원본 해상도 1,200프레임을 다시 변환하며 이미지 해시·크기·좌표 범위·프레임 ID를 확인했다.
- 차선 곡선 3,924개와 차량 상자 7,405개를 `coordinate_frames.jsonl`에 원본 프레임 정보와 함께 저장했다. 좌표는 기존 초안에서 가져왔고, 사용자 육안 승인 기록을 별도 보존했다.
- 기존 정답지의 사건 11건과 기록된 시작 시각 9개를 `events.truth.json`으로 가져왔다. 시작 시각이 없는 2건은 null로 유지했다. 기존 위반 시작 시각을 정밀 기하 교차 시각으로 바꾸지 않았다.
- 선택한 보정 조건의 후보 2개를 정답 시간대와 대조하고 사건별 JSON·CSV 결과를 저장했다.

개별 프레임 ID·차량 ID·차선 속성이 확정된 새 검수 파일은 이번 채팅에 제공되지 않았다. 따라서 프레임별 reviewed 필드와 미정 속성은 유지했다. 전체 육안 승인 기록을 특정 1,200프레임의 좌표·추적 ID 정답 확정으로 확대하지 않는다. 같은 L3 출력에서 가져온 좌표로 L3를 자기 평가해 정확도를 계산하지 않았다.

## 시간대 대조 결과

조건은 **같은 영상에서 후보 대표 시각이 기존 사건 구간 안에 들어오는가**이다. 표시용 후보 창이 겹치기만 하는 경우는 포함하지 않는다. 두 추적기의 후보가 같은 사건 구간에 들어와도 해당 정답 구간은 한 번만 센다.

| 범위 | 기존 정답 구간 | 후보 대표 시각이 있는 구간 |
| --- | ---: | ---: |
| calibration | 2 | 0 |
| comparison | 9 | 1 |
| 전체 개발 데이터 | 11 | 1 |

두 추적기 모두 C00의 10–14초 구간에 13.501초 후보를 냈다. 기존 위반 시작 시각 12초보다 1.501초 뒤지만, 이 차이는 정밀 교차 시각 오차가 아니다. 차량·차선 ID 일치와 위반 유형은 평가하지 않았으므로 precision·recall은 null이다.

후보가 없는 10구간은 141927(4–10초), youtube_clip_01(0–2초), C05(10–12초·20–22초), C09(9–11초), C39(52–55초), C47(0.5–3초), C10(7–9초), C28(9–10초), C44(28–30초)다. C05 두 번째 구간은 앞선 사용자 관찰과 충돌한 상태를 보존했으며 이번 대조에서 기존 정답을 삭제하지 않았다.

다음 작업은 이 목록에서 차량 관측 공백, 차선 연결, 작은·경계 차량 보류, 교차 지속 조건 중 어느 단계가 후보를 막았는지 확인하는 것이다. 유형 분류·전체 모델 선정·정상 및 독립 영상 검증은 남아 있다.
