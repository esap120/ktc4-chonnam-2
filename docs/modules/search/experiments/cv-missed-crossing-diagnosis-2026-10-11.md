# CV 교차 후보 누락 진단과 C09 상태 오류 수정

작성일: 2026-10-11. 기존 15개 개발 영상·3,233프레임·V1/L3/두 추적기 캐시를 고정했다. 기존 정답 사건과 시각을 재사용했으며 추가 사건 입력이나 사용자 재검수를 요구하지 않았다.

## 결과

**연속으로 유효한 관측이 들어오는데 오래된 관측으로 오인해 교차 근거를 지우던 오류를 수정했다. C09 약9.87초 후보가 두 추적기에서 복구됐고, 기존 C00 약13.50초 후보는 그대로 유지됐다.** 후보 수는2→4, 후보가 들어 있는 기존 정답 시간대는11개 중1→2개다. 두 추적기가 같은 구간을 각각 기록하므로4개 후보가4개 사건을 뜻하지 않는다.

이는 시간대 포함 여부이며 사건 recall·precision은 계산하지 않았다. 대상 차량·정답 차선의 ID 일치, 실제 타이어 접지, 실선/점선·중앙선 역할과 위반 여부는 아직 평가하지 않았다. 후보 의미와 점수는 UNKNOWN/null을 유지한다. 현재 구조는 bbox 아래쪽 중앙점과 차선 곡선의 거리 부호 변화를 확인한다.

| 지표 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 전체 영상 / 프레임 | 15 / 3,233 | 15 / 3,233 |
| ByteTrack 후보 | 1 | 2 |
| BoT-SORT 후보 | 1 | 2 |
| 후보가 포함된 정답 구간 | C00, 1/11 | C00·C09, 2/11 |
| 후보 없는 정답 구간 | 10 | 9 |

입력 해시와 모든 규칙이 동일하다. **3,233개 프레임별 차선·차량·거리·보정 기록은 수정 전과 바이트 단위로 동일**하고 기존 C00 후보2개도 필드 전체가 동일하다. 차이는 상태 전이 결과의 C09 후보 추가다. 모델 재추론·재학습·외부 API 호출은 없었다.
