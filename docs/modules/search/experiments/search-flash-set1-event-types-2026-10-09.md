작성일·실행일: 2026-10-09. 상태: **스트리밍 A/B ×3회 완료(영상 밖 후보 오류 포함), A 2·1·1/11 vs B 0·0·0/11**. ₩6,000·500만 토큰 승인 내에서 이전 첫 회차를 보존하고 남은 회차를 완료했다. 최신 결론은 마지막 최종 결과 절을 따른다.

기존 [sol Fine720 set1 실험](search-v3-gpt-sol-fine720-set1-2026-10-04.md)은 최종 검출 1·1·1/11, Coarse 겹침 4/33이었다. Flash의 PM probe 추정치 약 2.2/11은 참고값으로만 취급하고 이번 A 조건 결과로 운영 조건 기준선을 새로 기록한다.

## 측정과 사전 판단 기준

순위는 **클립의 전체 유형 후보**를 score 내림차순, `at_sec` 오름차순으로 정렬한다. 정답 유형만 먼저 골라 순위를 다시 매기지 않는다. 원본 초에서 `candidate.start < truth.end`와 `truth.start < candidate.end`를 모두 만족해야 본문 겹침으로 인정한다. Fine padding 구간이 정답을 포함하는 것만으로는 적중이 아니다.

| 지표 | 정의·보고 방식 |
| --- | --- |
| **최종 검출 — 주 지표** | top-3 안의 정답 유형 후보 본문이 사건 구간과 겹치고, 연결된 Fine이 오류 없는 `OBSERVED`와 같은 유형을 반환한 사건 수. 회차별 n/11·3회 평균을 기록하고 rank1도 함께 보고 |
| Coarse 겹침 | 정답 유형 후보 본문이 사건 구간과 겹친 사건 수. 전체 후보 기준 3회 합계 n/33, 회차별 n/11도 기록 |
| 후보 수 | 조건별 클립당 평균·최대, 유형별 수. 정상·양성을 나누어 기록 |
| 틀린 유형 후보 | B 양성 클립에서 그 클립의 라벨 유형과 다른 후보 수. 미라벨 사건 가능성이 있으므로 확정 오탐과 구분 |
| 정상 클립 OBSERVED | 조건별 3클립 × 3회에서 발생한 클립·호출 수와 유형. 정상 기각·불확실·실패를 분리 |
| 비용·지연 | 조건/회차별 입력·출력·총 토큰, Coarse/Fine provider 지연 p50, wall-clock, Fine 시도·성공·실패 수. usage 누락은 0으로 대체하지 않음 |

사건별 실패는 분모에서 빼지 않고 별도 표기한다. 정상 입력 준비 실패는 정상 기각으로 세지 않는다. 대상 차량 GT가 충분하지 않으므로 주 지표를 차량까지 검증된 recall로 표현하지 않는다. 육안 검토 결과는 수치와 나란히 보고한다.

판단은 실행 전에 다음으로 고정한다.

- **B의 top-3 최종 검출이 A보다 회차 평균 1건 이상 낮거나, Coarse 겹침이 3/33 이상 낮으면:** 4개 동시 입력에 영향이 있다고 #313에 보고한다. 유형별 Coarse 호출·유형 우선순위 프롬프트는 후속 대안으로 제시하되 이번 실험에 추가하지 않는다.
- **차이가 그보다 작으면:** 이번 개발 표본에서는 방침 변경 근거를 확보하지 못한 것으로 기록하고 4개 동시 입력을 유지하는 의견을 남긴다. 성능이 동일하거나 비열등하다는 통계적 결론으로 표현하지 않는다.
- rank1 변화, 틀린 유형 후보·오탐·비용 증가, 오류로 인한 미완료 여부도 별도로 보고한다. 미완료 실행은 유지/변경 결론을 확정하지 않는다.
- **#240:** A의 Flash 운영 조건 결과와 기존 sol Fine720의 1·1·1/11을 같은 사건 분모로 나란히 기록한다. 기존 sol 결과는 이미지 전송·Fine720·과거 실행이며 새 채점과 완전히 같지 않을 수 있음을 명시한다. 이 실험만으로 모델 교체를 결정하지 않는다.
