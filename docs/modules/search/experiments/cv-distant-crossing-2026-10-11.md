# 원거리 차량 교차 후보 복구 실험

작성일: 2026-10-11. C09 상태 오류 수정 이후의15개 개발 영상·3,233프레임을 사용했다. 사건 정보와 시각은 기존 정답에서 재사용했다.

## 결과

**작은 차량의 판단 보류 조건을 낮춘 실험 설정에서 C10 약8.54초와 C44 약28.59초 후보를 복구했다.** 기존 C00·C09 후보4개는 필드 전체가 동일하게 유지됐다. 후보는4→7개, 후보가 포함된 정답 시간대는11개 중2→4개다. 두 추적기가 같은 차량을 각각 기록하므로7개 후보가7개 사건을 뜻하지 않는다.

| 지표 | 이전 기준 설정 | 원거리 실험 설정 |
| --- | ---: | ---: |
| ByteTrack 후보 | 2 | 3 |
| BoT-SORT 후보 | 2 | 4 |
| 전체 후보 | 4 | 7 |
| 후보가 있는 정답 시간대 | C00·C09, 2/11 | C00·C09·C10·C44, 4/11 |
| 후보 없는 정답 시간대 | 9 | 7 |

**시간대 포함 여부이며 사건 recall·precision은 아니다.** 대상 차량·정답 차선의 ID 일치, 타이어 접지와 위반 유형은 미평가다. 후보 의미는 UNKNOWN, 점수는null을 유지했다. 같은 개발 영상을 보며 설정을 비교한 결과로 독립 데이터 성능이나 일반적인 정확도 향상을 확정하지 않는다.

## 원인과 변경 범위

640×360 입력의 기존 최소 차량 상자는32×18px였다. C10·C44의 최종 확인 상자는 각각19×15px와19×14px로, 실제 차량 관측과 차선 연결이 이어져도 크기 규칙 때문에 거리 표본을 만들지 않았다.

새 실험 설정은 최소 폭 비율0.05→0.025, 높이 비율0.05→0.035로 변경했다. 640×360에서는16×12.6px다. 여전히 더 작은 관측은 보류한다. 기존 deadband2px, 반대쪽3회·0.4초 유지, 관측 공백0.45초 제한, 경계·중복·차선 점프·보정·장면 전환 보호는 유지했다. **Python 소스와 기본 규칙은 변경하지 않았으며 별도 `experimental-rules.json`으로 검증했다.** 모델 재추론·재학습·외부 API 호출도 없었다.

입력 해시·코드 해시가 모두 동일하다. 전체3,233프레임의 원본 정보·보정·차선·차량 관측이 이전 결과와 정확히 같다. 거리 표본만 추가됐으며 실제 전체 CLI에서7개 후보를 생성했다.

## 복구 후보의 실제 근거

| 구간·추적기·ID | 이전 쪽 | 반대쪽 시작 | 확인 | 결과 |
| --- | --- | --- | --- | --- |
| C10 BoT-SORT T11 / L52 | 8.4초, 27×19px, 거리−2.5px | 8.8초, 21×16px, +4.5px | 9.2초, 19×15px, +7.5px | 대표8.542857초, LEFT_TO_RIGHT |
| C44 ByteTrack T88 / L20 | 28.4초, 22×16px, −2.333px | 28.8초, 21×16px, +2.5px | 29.2초, 19×14px, +7.5px | 대표28.593103초, LEFT_TO_RIGHT |
| C44 BoT-SORT T92 / L20 | 같은 검출 상자·시각 | 같은 검출 상자·시각 | 같은 검출 상자·시각 | 같은 물리적 구간의 별도 추적 기록 |

각 구간의 관측은0.2초 간격으로 이어졌다. 이전 쪽과 첫 반대쪽 사이0.4초에는 중립 표본이 있으며 관측 공백이 아니다. C10 차선L52는5.8–19초, C44 L20은11.8–29.6초에 같은ID·source slot0으로 이어졌다. 확인 전 보정 reset이나 갑작스러운 선ID 교체는 없었다.

이전 쪽→확인 시점의 차량 접지 대리점 X이동은 C10 +14px, C44 +11.5px다. 해당 높이의 선 X이동은 각각+4px와+1.667px로, 단순한 선 점프보다 차량의 상대 이동이 우세했다. 실제 원본과 출력 영상에서 작은 차량과 왼쪽 주행 차선 경계의 관계를 확인했다.

C10은 BoT-SORT에서만 복구됐다. 같은 검출에 대응하는 ByteTrack 관측ID가8.4초까지3, 8.6초부터2로 바뀌어 교차 전후 근거가 이어지지 않았다. 임의로 서로 다른 차량ID를 붙이지 않았다. 근거는 `c10-tracker-comparison.json`이다.

초기 거리의 deadband 초과 여유는 C10 0.5px, C44 약0.333px로 작다. 이후 반대쪽 거리 증가와 연속 유지가 후보 생성을 뒷받침하지만, 지속적인 위치 편향이 실제 교차처럼 보일 가능성은 별도 평가해야 한다. 두 추적기가 같은 검출을 사용하므로 독립적인 정확도 증거가 아니다.

## 크기 규칙 민감도

기존 보정 기록을 고정하고 폭·높이 최소 비율을 함께 바꾼5개 전체 캐시 재생을 비교했다. C09 수정 코드는 모든 조건에서 동일하다.

| 0.04 | 4 | 2/11 |

크기 제한을 완전히 없애지 않아도 같은 복구 후보를 얻었다. 실험 설정에서도 작은 상자 보류는 ByteTrack 3,529회·BoT-SORT 3,346회 남았다. 전체 거리 표본은12,277→18,559 및12,417→18,879개다. 표본 수와 보류 수는 정확도 지표가 아니다. 정상 영상 오탐 평가가 없으므로 이 설정을 운영 최적값으로 선정하지 않았다.
